取证发现的缺陷

取证发现的缺陷：浏览器取证抓到 7 个真实缺陷，其中 4 个是静态源码扫描完全发现不了的。

浏览器取证抓到 7 个真实缺陷，其中 4 个是静态源码扫描完全发现不了的 —— 静态扫描能证明「代码里没这么写」，却证明不了「页面上真的有内容、真的能用」。

# 缺陷 现象 根因 处置 严重度
1 护眼遮罩恒显 未达阈值也一直弹遮罩 模板 ref 拿到的是深层 reactive 代理，嵌套 ref 被自动解包 → eye.eyeIntervalMin 拿到数字而非 Ref 改共享单例 + StudyTemplateRefUnwrapTest P1
2 词库页空态 背单词页不显示任何词 页面未显式传 lineType='IN' 页面显式传参 P1
3 语法页字段口径不一致 语法点列表空白 后端 VO 返回 items，前端读 list 以 items 为准改前端 P1
4 语法点表无种子 语法页 11 个语法点全空 study_grammar_point 灌库时遗漏 新增增量脚本 18-seed-grammar-point.sql + StudyGrammarSeedTest P1
5 护眼页拿不到护眼状态 显示不出「提醒间隔」 provide/inject 方向反了 —— 布局是页面的子组件，页面 inject 不到 改模块级共享单例（ADR-032） P1
6 护眼会话切页后静默停摆 用眼时长不再累计，无报错 状态工厂里注册 onMounted，绑到第一个调用者 生命周期归学习端布局（ADR-032） P1
7 家长端窄屏被整个盖住 390/768px 下家长端 3 页被抽屉 + 遮罩压住，直接不可用 上游 layouts/default/sider/index.vue:2-12 在 <992px 把侧栏渲染成常开抽屉 + 遮罩；家长端菜单独挂在管理端布局 StudyParentShell 改全屏固定层 + 自带 3 项导航与登出（ADR-033） P0

3.1 两个 Vue 3 硬语义（本轮最贵的认知）

缺陷 1 / 5 / 6 指向同一条链上的三个不同的 Vue 3 语义，每一个单独看都像「代码写对了」：

# 语义 后果
1 provide/inject 是「父 provide → 子 inject」 页面模板写 <StudyLayout> ⇒ 布局是页面的子组件 ⇒ 页面 inject() 拿不到布局 provide() 的值，且不报错
2 模板 ref 拿到的是深层 reactive 代理，嵌套 ref 被自动解包 eye.eyeIntervalMin 拿到数字而非 Ref，.value 恒 undefined；而 undefined?.value 静默通过，表现为「数据为空」
3 onMounted 绑定的是「当前正在 setup 的组件实例」 状态工厂里写 onMounted ⇒ 钩子归第一个调用者 ⇒ 路由切换后会话静默停摆

处置不是「再调一次代码」，而是用架构约束把错误写不出来：状态工厂不得注册任何生命周期钩子，会话生命周期由明确的宿主组件（学习端布局）持有；跨组件传状态统一走模块级共享单例。见 ADR-032。

3.2 家长端窄屏（P0）的处置取舍

备选 结论
A. 新建 layouts/parent 目录 ❌ 上游 transformObjToRoute 对 DB 菜单一律挂 LAYOUT，动态菜单永远无法用自定义布局；改它要动上游路由内核，还要处理与 DB 菜单同路径冲突
B. 改上游 layouts/default 的断点行为 ❌ 违反「上游基座零改动」约定
C. StudyParentShell 改全屏固定层 ✅ 采纳：position: fixed; inset: 0; z-index: 1100 盖住管理端抽屉/遮罩/顶栏/侧栏，并在本产品目录内自带 3 项导航 + 登出

盖住管理端顶栏后家长端就没有导航与退出路径了 —— 所以自带导航与登出不是额外功能，是必要的补偿。见 ADR-033。

4.3 故障注入：绿 → 红 → 绿闭环

两条新断言都做了故障注入验证，确认它们真的能拦住回归：

注入 期望 实测
把外壳的 position: fixed 改成 relative 家长端断言变红 ✅ 变红
把 onMounted 塞回护眼状态工厂 护眼断言变红 ✅ 变红
还原 全绿 ✅ 全绿

踩坑（重要）：这两条断言首次跑就绿，但注入故障后仍然是绿 —— 原因是注释里出现了同名字样（例如注释写「不使用 position: fixed」也被字面量扫描命中）。 修法：先剥注释再判定。这个坑同时说明：字面量扫描类断言必须显式处理注释，否则它什么也拦不住。

4.4 既有断言触发后的处置（全部改生产侧）

本轮触发既有断言 3 次，全部改生产侧，0 处改既有断言：

# 触发点 生产侧处置
1 f16_noHorizontalScrollOnNarrowScreen 报家长端导航有 overflow-x: auto 改 flex-wrap: wrap 换行（横向滚动违反 F-16）
2 tc08_21_noHardcodedLightColor 误伤 CSS 属性 white-space 移除家长端两处 white-space

口径：断言红 = 生产侧有问题就改生产侧；断言本身有缺陷时按「更精确」修，而不是放宽。

# 边界 原因 建议
1 家长端暗色模式下仍有上游 @content-bg 的亮色残留 上游 layouts/default 的 @content-bg 没有暗色覆盖；改它违反「上游基座零改动」 暂不处理；家长端本身是全屏固定层，不依赖上游背景变量。若后续家长端要支持暗色，需在 StudyParentShell 内自带暗色变量

3 浏览器取证未覆盖全部 44 个测试项 取证聚焦「10 个有页面的路由」，其余为接口/数据层用例 接口层已由 300 条自动化覆盖
4 浏览器取证未做交互链路全流程点击录制 本轮口径是「渲染 + 量测 + 截图」 关键链路（答一题 → 出解析 → 入错题池）已有 P1 端到端 48/48 接口断言覆盖
