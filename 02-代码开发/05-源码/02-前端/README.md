## 3 四套形态，别混用

| | 管理端（12 页） | 家长端（7 页） | 学习端（19 页） | 孩子端（1 页） |
|---|---|---|---|---|
| 布局 | JeecgBoot 标准布局（顶栏 + 侧栏） | **独立全屏 `layouts/parent`** | **独立全屏 `layouts/study`** | 独立全屏 `layouts/child` |
| 列表页方案 | `useListPage` + Ant Design Vue 原生组件 | 独立实现 | 不套列表页方案 | — |
| 配色 | 底座主色 `#1890ff` | 跟随全局暗色 | 按《产品设计规范》学习端专项 | 同学习端 |
| 可见数据 | 管理维度 | **仅关联孩子**（可切换视角） | 当前孩子 | 仅自己 |
| 护眼 | 无 | 无 | 用眼统计 / 蓝光过滤 / 休息提醒 | 同学习端 |

> **家长端也是独立全屏布局**（契约 §1.3）——不与孩子端共用 `layouts/study`，家长端不吃学习端的浅色锁定与护眼遮罩。

## 4 铁律

| # | 规则 | 出处 |
|---|---|---|
| 1 | 配色、布局、尺寸、间距、字体字号**一律沿用**《产品设计规范》，不引入新色值 | 产品设计规范 |
| 2 | 移动视口 **390px 不得横向溢出** | N-08 / 产品设计规范 |
| 3 | 表格首列只放短标签；长描述放第二列或用可折行 `span` 包裹 | 产品设计规范 §禁止事项 |
| 4 | 答案区初始态**不渲染到 DOM**（不是 `display:none`） | R-01 / ADR-009 |
| 5 | 家长端不出现 rank/percentile 字段与排名文案 | R-04 |
| 6 | **家长之间互不可见**；**禁止家庭内比较措辞**（「更 / 比 / 超过」类） | R-04 强化 / `R04-5` `R04-6` |
| 7 | 不引入第三方统计 / 广告 / 崩溃上报 SDK | N-06 |
| 8 | 统一用 `defHttp`；API 函数集中在 API 层，不在 `.vue` 里散写 URL | 知识库 §5.1 |
| 9 | 判对错、涉及分数的展示必须标注**判定来源（非 AI）** | 产品设计规范 §禁止事项 |
| 10 | 家长端接口失败按 **4010（越权）** 处理，不把「无权」显示成「不存在」 | ADR-018 |

## 5 护眼实现要点

| 项 | 实现 | 注意 |
|---|---|---|
| 用眼时长 | **服务端心跳**累计，不信任客户端上报 | ADR-010；客户端关页会漏记 |
| 蓝光过滤 | 容器 `filter` 属性 | 断言要读 computed style，不要靠截图 |
| 休息提醒 | 达阈值出**不可绕过**的遮罩 | 遮罩不得自动消失；学习端**不显示时长数字** |
| 间隔可配 | 家长端配置 → 学习端生效 | 配置走 `PUT /context/{id}/eye-interval` |

## 7 什么时候需要动这个目录

| 场景 | 动作 |
|---|---|
| 写页面 | 先在《前端页面清单》补条目，再落地到 `src/views/study/` 对应端目录 |
| 只改设计 | **不动本目录**，改 `../../04-前端页面/` 的源稿后重新生成 HTML |
| 升级基座 | 与后端同 tag 升级，避免 `jeecgboot-vue3` 与 `jeecg-boot` 版本不一致 |
