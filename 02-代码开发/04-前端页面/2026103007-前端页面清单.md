### 1.2 路由前缀

| 前缀 | 用途 | 角色 |
|------|------|------|
| `/study/kid/**` | 学习端 | kid |
| `/study/parent/**` | 家长端 | parent |
| `/study/manage/**` | 管理端 | admin |

> 孩子端登录页挂在 `/study/kid/**` 下（`/study/kid/login`）；《多用户改造契约》§7 记的 `/kid/login`、`/parent/family` 等是**去掉 `/study` 前缀的相对写法**，两者一一对应。
> `POST /kid/lookup`、`POST /kid/login` 是**免认证**路径，其余业务接口一律需要 token。

### 1.3 布局差异

| 端 | 布局 | 说明 |
|----|------|------|
| 管理端 | JeecgBoot 默认布局（顶栏 + 侧栏 + 内容区） | 直接复用底座 `layouts/default` |
| 家长端 | **独立全屏布局** `layouts/parent` | **不吃管理端顶栏与侧栏**；顶部只有孩子切换条与家庭入口。只读数据页隐藏「新增/编辑」类操作列 |
| 学习端 / 孩子端 | **独立全屏布局** `layouts/study` | 孩子端需要沉浸与聚焦；孩子登录页 `/study/kid/login` 同样走这套布局 |

> **学习端与家长端都是独立全屏布局**——这是本项目与既有系统最大的结构差异。实现方式：新增 `layouts/study/index.vue`（学习端 / 孩子端）与 `layouts/parent/index.vue`（家长端），在路由 meta 上标记 `layout: 'study'` / `layout: 'parent'`；管理端继续用底座 `layouts/default`。详见 §6.4。

## 管理端页面详规

> 全部遵循《产品设计规范》第 9.1 节列表页骨架：**`PageWrapper`（内容区 margin:16px）→ `useListPage` + `BasicTable`**（查询区 / 工具栏 / 分页 / 表格设置均由组件内置）→（可选）统计区 → 操作列插槽 `StudyActionColumn` → 弹窗。
> **禁止**手写 `a-table`、**禁止**另做分页组件、**禁止**把查询表单与表格混排（规范 9.1 / 8.2 / 8.9）。

### 3.1 全局上下文配置

| 项 | 内容 |
|----|------|
| 布局 | 独立表单页（非列表页）：`PageWrapper` 内 `a-form`（管理端沿用基座默认 `layout="horizontal"`，规范 8.4①），`a-row :gutter="16"`（规范 6.2） |

| 家长 | 底座原生账号 + 密码 | `POST /sys/login`（页面 `/login`，底座自带，**不新增**） | 家长端（`layouts/parent`，独立全屏布局） |
| 孩子 | **家庭码 + PIN 两步** | `POST /kid/lookup` → `POST /kid/login`（两步均免认证） | 学习端（`layouts/study`，独立全屏布局） |
| 管理员 | 底座原生账号 + 密码 | `POST /sys/login` | 管理端（`layouts/default`） |

家长账号走 JeecgBoot 原生登录页，**不新增家长登录接口**；孩子端是**独立的两步登录**，**不暴露**底座登录页与管理端任何入口——孩子端首屏固定为 `/study/kid/login`，未登录时管理端与家长端路由一律不可达。

### 6.2 界面 → 可见数据

> 隔离由服务端强制：家长请求用 `ChildScopeHelper.childIdsOf(currentUserId)` 取 child_id 集合拼 where 条件；孩子请求用 JWT 携带的 `childId`。**前端传入的 `childId` 不作为唯一依据**，越权一律返回 **4010**（不返回 404，避免探测）。

| 界面 | 可见数据 | 判定来源 | 越权表现 |
|---|---|---|---|
| 家长端全部页面 | 仅 `study_parent_child_rel` 中与当前家长关联的孩子及其数据 | 关系表实时查询 | 4010 |
| 学习端全部页面 | 仅当前孩子自己的数据 | JWT claim `childId` | 4010 |
| 孩子端登录页步骤① | 仅输入家庭码所属家庭的候选孩子（**只有 id / 昵称 / 头像**） | `POST /kid/lookup` 返回体 | 4009 家庭码不正确 |
| 跨家庭 | **不可见**；孩子归属唯一家庭，家长需先退出原家庭才能加入新家庭 | `study_child.family_id` | 4010 |
| 家长 A ↔ 家长 B | **互不可见**（反馈、评价、申诉一律隔离），且不做任何家庭内比较 | `study_parent_child_rel` | 4010 |

> **R-04 强化**：多家长场景下家长之间互不可见对方数据，也**不得**出现「谁的孩子更…」「家长评分对比」一类文案（契约 §3.3）。

### 6.3 孩子端两步登录（登录页规格）

| 步骤 | 界面 | 接口 | 正常结果 | 异常处理 |
|---|---|---|---|---|
| 步骤① 家庭码 | 输入 6 位大写字母数字家庭码；底部主按钮「下一步」 | `POST /kid/lookup` | 返回候选孩子列表（仅 id / 昵称 / 头像） | 家庭码错误 → 提示「家庭码不正确」（4009），**留在步骤①**，不进候选列表 |
| 步骤② 选孩子 + PIN | 候选头像列表 + PIN 输入（4–6 位数字）；底部主按钮「进入」 | `POST /kid/login` | 签发 token（携带 `childId` / `childCode` / `role=study_kid`），进入学习端 | PIN 错误 → 提示后**留在步骤②**可重试；**连续 5 次失败锁 10 分钟**，锁定期拒绝登录 |
| 退出 | 学习端顶栏「退出」 | `POST /kid/logout` | 清会话回到步骤① | — |

**明文与锁定规则**：

| 项 | 规则 |
|---|---|
| 家庭码 | 由家长在家长端生成 / 重置，**明文只在生成时返回一次**，之后任何界面都不能再查看（库里只存哈希） |
| PIN | 家长重置 PIN 时**明文仅本次显示**，必须当场抄下；孩子端登录框不提供「忘记 PIN」自助入口 |
| 候选列表 | 只返回 `id` / `nickname` / `avatar`，不返回账号、年级、生日等任何其他信息 |
| 锁定 | 失败 5 次锁 10 分钟（`pin_fail_count` / `pin_lock_until`）；锁定提示只说「请稍后再试」，**不暴露失败次数**（规范 10.3④：中性表述，不做负向文案） |

**设计规范落点**（孩子登录页 `/study/kid/login`）：规范 9.8 孩子端布局（复用 `layouts/study`）；10.2 学习端页面骨架（顶栏 48px、主任务区 padding 16px、底部主操作条 64px 安全区适配）；10.1 字号（正文 16px、主按钮文字 18px、辅助说明 14px）；10.2 学习端圆角 12px；8.1 按钮高度学习端 ≥44px；4.2③ 根节点锁定 `data-theme="light"`；3.1 / 3.2 颜色走主题令牌、4.2① 不硬编码 hex；9.8 两步登录顺序与错误态不泄露他人信息。

## 护眼前端实现

### 9.1 状态机

```
IDLE ──(开始会话)──▶ COUNTING ──(达阈值)──▶ BLOCKED
  ▲                    │                        │
  └────(会话结束)──────┴────(用户确认)─────────┘
```

### 9.2 实现要点

| 要点 | 实现 |
|------|------|
| 计时基准 | **服务端心跳**。客户端每 30 秒上报一次 `active`；服务端按心跳累加（接口设计 8.2） |
| 阈值 | `context.eyeIntervalMin`（默认 15 分钟；低年级 10、高年级 20） |
| 阻断 | 遮罩 `z-index` 高于所有内容；**不可自动消失**，必须点击确认 |
| 引导文案 | 「看向 6 米外的地方，保持 20 秒」——具体动作，不只写「休息一下」 |
| 蓝光过滤 | 容器 `filter: sepia(...)` 类滤镜；状态存 localStorage + 服务端 |
| 切后台 | `visibilitychange` 隐藏时暂停心跳，恢复时重置计时（离开屏幕不算用眼） |
| 页面卸载 | `beforeunload` 上报会话结束，避免时长漏记 |
| 孩子端不显示时长 | 只显示状态图标（规范 10.5） |

| 项 | 值 |
|----|------|

| 卡片 | 白底，圆角 12px（学习端），padding 24px |
