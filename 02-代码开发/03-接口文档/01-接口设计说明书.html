错误码表

失败语义

错误码表

2.1 业务错误码

码 含义 HTTP 触发场景
4001 缺少错因 400 提交练习未选错因
4002 前置步骤未完成 400 写作未过提纲提交初稿
4003 违反练习顺序 400 未作答就请求解析
4004 上下文未配置 400 首次使用未配置地区/教材
4005 判定策略缺失 500 该题型未注册 JudgeStrategy
4006 版权信息不完整 400 导入非自编题目未填 source_ref
4007 母题结构不完整 400 母题五段缺任一段
4008 变式不足 400 过关要求 N 道变式但不足
4009 家庭码不正确 400 孩子端 POST /kid/lookup 家庭码校验失败
4010 越权 403 家长访问非关联孩子的数据 / 孩子访问他人数据

4010 为什么不是 404：若越权访问返回 404，攻击者可借「404 vs 200」区分资源是否存在（资源探测 / 枚举 childCode）。返回统一的 4010 表示「你无权访问」，无论该资源是否存在，响应形态完全一致，无法反推资源存在性。

触发场景：家长请求的 childCode 不在 study_parent_child_rel 关联集合内；孩子 token 的 childId 与目标资源归属不一致。

业务错误码一律返回 HTTP 200 + code != 0（见 2.2 约定），表中 HTTP 列仅标注语义状态。

2.2 通用 HTTP 码

码 含义
200 成功
400 参数错误
401 未登录 / token 失效
403 无权限（角色不符或缺权限码）
404 资源不存在
405 方法不允许
500 服务端异常

约定：业务错误一律返回 HTTP 200 + code != 0，由前端按 success 判断；仅鉴权与路由错误使用 4xx/5xx。这与 JeecgBoot 的 Result 处理一致。

10.2 家长登录：不新增接口

家长直接用 JeecgBoot 原生登录 POST /sys/login，本项目不新增任何家长登录接口。理由：

# 理由
1 复用底座现成的 Shiro + JWT + Redis 会话、密码策略、登录审计、验证码，不重复造轮子
2 家长就是 sys_user + 角色 study_parent，底座 /sys/login 签发的 token 与孩子 token 同构，前端拦截器统一
3 不新增接口 = 不引入第二套认证栈，避免两套令牌语义、过期策略、踢下线逻辑不一致
4 底座 /sys/login 的请求/响应体保持原样，study 模块不包裹、不改字段

13.1 家长侧 study:parent:* 与孩子侧 study:kid:* 的划分

维度 家长侧 study:parent:* 孩子侧 study:kid:*
承载角色 study_parent（家长账号，密码登录） study_kid（孩子账号，PIN 登录）
能做什么 家庭与成员管理、孩子档案管理与 PIN 重置、家长↔孩子关联、只读查看关联孩子的数据、提交反馈与申诉 查看自己的信息、退出登录
不能做什么 不得作答、不得改错因、不得查看未关联孩子的数据 不得查看其他孩子的数据、不得管理家庭成员
