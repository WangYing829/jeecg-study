# 术语表

> **术语是防漂移的。** AI 在不同会话里把「变式」「母题」「错因」理解成不同东西，产出会互相打架。
> 本表是**唯一术语来源**；PRD / 设计文档 / 代码命名与本表冲突时，以本表为准并回头修文档。

## 1 底座五组件（`F-BASE-01`…`05`）

| 术语 | 定义 | 不是什么 |
|---|---|---|
| **全局上下文** | 一次配置（省 + 学段 + 年级 + 教材版本）全局生效的组合。存在 `study_context`，用 `StudyContextHolder`（ThreadLocal）持有 | 不是「用户设置」，切换后历史记录仍按原上下文解析 |
| **坐标树** | 四层结构：**地区考纲 → 学科 → 单元 → 考点**。节点支持版本化与失效标记（`status=0` + `invalid_at`），**失效不删除** | 不是普通分类树；旧节点失效后历史错题仍要能解析到 |
| **统一 ID 体系** | 全局唯一且不复用的 ID。前缀：`KPT-`（考点）`QST-`（题目）`MTH-`（母题）`WRD-`（单词）`GRP-`（语法点）`WRT-`（写作）`ERR-`（错题） | 不是数据库自增主键；失效后 ID **不回收** |
| **统一错题池** | 全模块共用的错题收口。录入 → 错因必填 → 排期 → 重做 → 变式 | 不是「各模块自己的错题列表」 |
| **统一复习调度** | 排期规则：**当日 / +1 / +3 / +7**，**连续三次做对才移出**队列 | 不是固定间隔重复；不是做对一次就毕业 |

## 2 错题与复盘（模块②）

| 术语 | 定义 |
|---|---|
| **错因五维** | 固定五档：**概念不清 / 审题偏差 / 计算失误 / 方法不会 / 时间不够**（`F-WRG-01`）。答完题**必须选一个才能提交**——是必答的一个问题，不是可跳过的菜单 |
| **重做队列** | 到期可重做的错题集合，由统一复习调度产出 |
| **一题多变** | 同一考点下生成多个变式题（`F-WRG-03`） |
| **错因频次统计** | 记录每个错因标签的使用频次（首版五维固定，但为后续扩展留口） |

> **五维是首版妥协**：竞品证据（A+ 错题本自定义错因）要求错因由真实错题反推，与固定五维冲突。工程化处理为「首版固定 + 记录频次 + V1 后复评」。这是 ADR-006。

## 3 背单词（模块③）

| 术语 | 定义 |
|---|---|
| **课内线 / 课外线** | 课内 = 教材单元 1:1 映射的词表（**优先**）；课外 = 课内升级项（`F-WRD-05`） |
| **四档反馈** | **认识 / 模糊 / 忘记 / 熟知**（`F-WRD-04`）。**不是对/错**。四档映射到不同的遗忘衰减更新 |
| **连续天数** | 完成练习的连续天数（`F-WRD-02`），属于「完成度优先」路线 |

## 4 数学母题（模块④）

| 术语 | 定义 |
|---|---|
| **母题** | 一道题型的**五段结构**实体（`F-MTH-01`），强制五段齐全，缺一段不允许保存 |
| **三层变式** | 母题的结构化变式生成（`F-MTH-02`） |
| **过关判据** | 变式全对 **且** 能口述关键关系才算过关（`F-MTH-03`） |
| **错因二分** | 数学侧错因与通用五维的映射关系 |

> **母题 vs 变式**：母题是「原型」，变式是「同一考点的另一道题」。**判对错永远走确定性规则，AI 只做解释**——变式生成是「结构化模板变换」，模型只做自然语言润色（ADR-007）。

## 5 英语语法（模块⑤）

| 术语 | 定义 |
|---|---|
| **句子变形器** | 把一个句子按语法规则变形（`F-GRM-02`） |
| **错误即入口** | 孩子写错的句子自动成为练习素材（不是错题本里的孤立条目） |
| **错句收藏馆** | 主动收藏的错句（`F-GRM-04`，P2 趣味玩法的一部分） |

## 6 语文写作（模块⑥）

| 术语 | 定义 |
|---|---|
| **六层拆解** | 名篇的六层拆解结构（`F-WRT-01`） |
| **对照式批改** | 与同题材佳作对照，**只给最该改的三条**（`F-WRT-03` 关联） |
| **三步训练流** | **审题 → 列提纲 → 写初稿**（`F-WRT-04`）。每步有系统反馈；**提纲这一步必须过才能写初稿**（防代写最有效的一步） |
| **温和分寸** | AI 反馈只在语法、逻辑、结构层面给温和建议，不下主观评价、不做情绪化评判（`F-WRT-07`） |
| **素材改情境库** | 同主题给不同处境 / 年龄 / 细节的**情境**，**不是金句**；强制填自己的经历（`F-WRT-03`） |

## 7 多用户与身份（模块 FAM，V1.1 新增）

| 术语 | 定义 | 不是什么 |
|---|---|---|
| **家庭（family）** | `study_family`。一个家庭包含若干家长成员与若干孩子档案。孩子**归属唯一家庭**；家长可加入一个家庭，需加入另一家庭须先退出当前家庭 | 不是租户；库里**没有** `tenant_id` |
| **家长成员** | `study_family_member`，关联底座 `sys_user`，角色 `OWNER`（创建者）/ `PARENT` | 不是独立账号体系——家长就是底座 `sys_user` |
| **孩子档案** | `study_child`，关联底座 `sys_user`（角色 `study_kid`），带昵称 / 头像 / 生日 / 年级 / PIN 哈希 | 不是「只读的学生表」——孩子**能自己登录** |
| **家长↔孩子关联** | `study_parent_child_rel`，**多对多**。唯一键 `uk_parent_child (parent_user_id, child_id)` | 不是 1:1 家庭关系表；唯一键是防重复关联的核心约束 |
| **家庭码** | 6 位大写字母数字，孩子端登录第一步用。**明文只在生成/重置时返回一次**，库里只存哈希 + 盐 | 不是密码；不是邀请码；不能公开列出所有孩子 |
| **孩子 PIN** | 4–6 位数字，孩子端登录第二步用。哈希存 `pin_hash` + `pin_salt`；**失败 5 次锁 10 分钟** | 不是「弱密码的密码」；强度要求低是因为低龄用户，靠锁定兜底 |
| **数据范围 / child_id 隔离** | 家长只见 `study_parent_child_rel` 中关联的 `child_id`；孩子只见自己的。**越权返 4010（不用 404，避免探测）** | 不是前端传 `childId` 就信；**Controller 不接受前端 `childId` 作为唯一依据** |
| **内容表 vs 行为表** | 7 张内容/知识库表**全局共享**（不按孩子复制）；7 张学习行为表**按 `child_id` 隔离** | 不是「所有表都加 `child_id`」——加了会让同一道题按孩子复制多份 |

> **身份三类**：家长（底座原生 `POST /sys/login`）/ 孩子（`POST /api/v1/study/kid/login`，两步）/ 管理员（底座 `admin` 角色）。
> **孩子两步登录**：`/kid/lookup`（家庭码 → 候选孩子列表）→ `/kid/login`（childId + PIN → JWT，token 带 `childId` claim）。
> 依据：`06-AI协作/01-任务台账/2026103019-多用户改造契约.md`。

## 8 家长端与护眼

| 术语 | 定义 |
|---|---|
| **护眼四项** | 用眼时长统计 / 蓝光过滤 / 定时休息提醒 / 提醒间隔可配（`F-EYE-01`…`04`）。**是产品指标不是营销词**（R-03） |
| **用眼时长** | 以**服务端心跳**累计，**不信任客户端上报**（ADR-010） |
| **客观趋势** | 家长端只看趋势与状态，**不做同龄排名**（R-04）。**V1.1 强化**：额外禁止家庭内比较、家长之间互不可见 |
| **切换孩子视角** | 家长端切换「查看哪个孩子」——**切的是视角，不是身份**。孩子端无此概念 |

## 9 工程术语

| 术语 | 定义 |
|---|---|
| **底座 / 共享组件** | 五个跨模块共用的能力（§1）。**V1 之前不得上线任何「内容型」模块**——底座没稳就堆内容等于制造积灰 |
| **单库** | 平台表（133 张）与业务表（17 张）同在 `jeecg-study`，**不用 `@DS` 切换**（ADR-015） |
| **单模块** | 只有 `jeecg-module-study` 一个业务模块，**域优先分包**（ADR-016） |
| **红线** | R-01…R-04，**发布否决项**，每个阶段都必须同时满足，缺一不发布 |
| **红线断言** | 24 条可执行断言（`03-测试验证/02-测试用例/` §10），把红线从口头约定变成可自动化的检查 |
| **追溯** | 需求 → 接口 → 用例的链路，机读在 `06-AI协作/01-任务台账/02-追溯矩阵.csv` |
| **AI 解释层** | AI 只生成讲解、追问、批改建议；**不产出对/错、不得分结论**（R-02） |
