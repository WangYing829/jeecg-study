## 3 源稿格式

源稿 = 一段 `<!--META {json} -->` 块 + Markdown 正文。

### 3.1 META 字段

| 字段 | 必填 | 说明 |
|------|------|------|
| `brand` | 是 | 侧栏品牌名，同时是移动端顶栏初始标题 |
| `title` | 是 | 页面主标题 |
| `kicker` | 是 | 标题上方的小标签 |
| `subtitle` | 是 | 副标题（摘要段） |
| `meta_line` | 是 | 品牌名下方的一行元信息 |
| `accent` | 否 | 主色覆盖，如 `#1890ff`；会自动派生 `--accent-ink/soft/line` |
| `facts` | 否 | 标题下的数据卡数组 `[{v, k}]` |
| `sections` | **是** | 章节数组，每项 `{id, nav, badge, num, tag}` |
| `side` | 否 | 侧栏小部件行 `[{label, pct, color, note}]` |
| `side_title` | 否 | 小部件标题 |
| `footer` | 否 | 页脚条目数组 |

**`sections` 的 `id` 必须与正文二级标题一一对应**：生成器按正文出现顺序把 `##` 切块，依次塞进 `sections`。数量或顺序对不上，内容会错位。

### 3.2 正文约定

| 写法 | 渲染为 |
|------|--------|
| `## 章节标题` | 一个 `<section>`，导航里出现一条 |
| `### 小节` | `<h4 class="sub-h">` |
| `#### 更小节` | `<h5 class="sub-h5">` |
| `\| a \| b \|` 管道表格 | `<table>`，自动包 `.tbl-wrap`（可横向滚动） |
| ` ```lang ` 围栏代码块 | `<pre class="cmd">`（深色、内部横向滚动） |
| 行内 `` `code` `` | `<code>`，长串自动换行 |
| `> 引用` | `<blockquote>` |
| `**粗体**` / `*斜体*` | `<strong>` / `<em>` |

## 5 浏览器校验台（真实渲染验证）

静态检查查不出横向溢出与交互失效，必须跑浏览器。

### 5.1 步骤

```powershell
# 1) 起本地服务
cd D:\DevProject\2-JavaPrj\20261030-jeecg-study
python -m http.server 8899 --bind 127.0.0.1

# 2) 生成校验台
python '.\05-公共资源\2026103014-生成校验台.py'

# 3) 浏览器打开
#    http://127.0.0.1:8899/03-测试验证/04-自动化测试/2026103014-校验台.html
```

### 5.2 校验台做什么

| 检查 | 方法 | 通过标准 |
|------|------|----------|
| 桌面横向溢出 | 每份文档放进 1280px iframe，读 `scrollWidth` vs `clientWidth` | 相等 |
| 移动横向溢出 | 每份文档放进 390px iframe，同上 | 相等 |
| 表格卡片化 | 390px 下查 `table` 的 `display` 与 `thead` 的 `display` | `block` / `none` |
| 移动端壳子 | 查 `.sidebar` 的 `position`、`.m-topbar` 的 `display`、`#fab` 是否存在 | `fixed` / `flex` / 存在 |
| FAB 出现 | 滚动 400px 后读 `#fab` 的 class | 含 `show`，且 `pointer-events:auto` |
| 面板展开 | 点 FAB，读 `.sidebar` / `#scrim` 的 class | 含 `open` / `show` |
| 遮罩关闭 | 点遮罩，再读 class | 两者都不含 |
| 顶部跳转 | 覆盖 `window.scrollTo` 记录目标，点「↑ 页面顶部」 | 记录到 `top=0` |
| 底部跳转 | 同上，点「↓ 页面底部」 | 记录到 `top=documentElement.scrollHeight` |
| 章节跳转 | 同上，点章节链接 | 记录到该节绝对位置 − 18 |
| 列名注入 | 读 `tbody td` 的 `data-label` | 等于对应列名 |

### 5.3 结果读取

校验台把结果写进 `#RESULT`（溢出检查）与 `#PROBE`（交互检查）两个 `<pre>`，页面标题会变成 `DONE bad=N` / `DONE2`。

## 6 踩过的坑（都已在脚本里修掉，别改回去）

| # | 坑 | 现象 | 现在的做法 |
|---|----|------|-----------|
| 1 | 导航链接渲染两遍 | 快速跳转与章节各渲染一次 → 滚动高亮与移动端标题错位 | 生成器拆成 `jump_links` 与 `chapter_links` |
| 2 | Markdown 围栏代码块没样式 | `<pre><code>` 拿不到 `pre.cmd` 的 `overflow-x:auto` → 代码块撑破页面 | 生成后正则把 `<pre>` 换成 `<pre class="cmd">` |
| 3 | 表首列 `white-space:nowrap` | 首列长文本撑出桌面横向溢出 | 本项目模板改 `white-space:normal` + `min-width:72px` |
| 4 | 行内 code 不换行 | 长路径/长 ID 撑破单元格 | `code{overflow-wrap:anywhere}`，但 `pre.cmd code` 保持 `white-space:pre` |
| 5 | `scroll-behavior:smooth` 读数假象 | 滚动后立刻读 `scrollY` 恒为 0，看起来像没滚 | 校验台先设 `scroll-behavior:auto` 再设 `scrollTop` |
| 6 | 视口外 iframe 不滚动 | 探针 iframe 排在 20 个 iframe 之下 → `scrollTo` 无效 | 探针 iframe 用 `position:fixed` 固定在视口内 |
| 7 | `markdown` 3.9 无 `get_output()` | `AttributeError` | 直接用 `md.convert()` 的返回值 |

```

2. 写 META：sections 与正文 ## 数量、顺序严格一致

5. 浏览器校验：起服务 → 生成校验台 → 浏览器打开 → 确认 bad=0 且 PROBE 全绿
6. 若动了 PRD / 接口 / 用例：
   python 05-公共资源\2026103015-追溯矩阵生成.py                   → 重跑矩阵
   python 05-公共资源\2026103016-红线断言检查.py                   → 红线门禁
7. 若动了数据库设计：python 05-公共资源\2026103017-DDL提取.py       → 重跑 SQL 真源
8. 在 00-项目说明.md 的目录树里补上这条产物
9. 在 CHANGELOG.md 记录变更
```

## 8 注意事项

| 项 | 说明 |
|----|------|
| 编码 | HTML 产出为 UTF-8 **无 BOM**；`.py` 为 UTF-8 无 BOM（Python 3 默认即可） |
| `.ps1` 脚本 | 含中文必须存 **UTF-8 带 BOM**，否则 PS 5.1 按 GBK 解码会吞换行符 |
| 产物可读性 | 不手改 HTML；所有内容改动都在源稿里做 |
| 源稿即交付 | `.md` 源稿与 `.html` 产物一起入库，便于 diff 与二次编辑 |
| 生成的 CSV | `02-追溯矩阵.csv` 与 `02-schema.sql` 等都是**脚本产物**，改源稿后重跑，不要手改 |
| CSV 的 BOM | `02-追溯矩阵.csv` **刻意用 UTF-8 带 BOM**（`utf-8-sig`），为的是 Excel 双击打开中文不乱码——**不是 bug**，别"修掉" |
| 门禁退出码 | 2 = 有缺口，**不是脚本坏了**。逐条判读后登记到任务台账 §5 |
| 术语一致 | 写文档前查 `06-AI协作/04-知识库/02-术语表.md`，不要自造术语 |
