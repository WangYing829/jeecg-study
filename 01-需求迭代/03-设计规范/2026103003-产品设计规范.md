本规范**不是新拟的**，而是从**开源 JeecgBoot v3.9.2 独立基座**的代码中**实测归纳**。每个数值都标注来源文件与行号，可回溯核对。

| 上游组件 | `src/components/`（Table / Form / Modal / Drawer / Description / Icon / Button / Page / Tree / Upload…） · `src/hooks/system/useListPage.ts` |

## 学习端专项规范

> 本节是 jeecg-study 新增部分，面向 7–15 岁孩子的学习界面。管理端规范在此**不适用**的地方以本节为准。

### 10.1 与管理端的三处关键差异

| 维度 | 管理端 | 学习端 | 理由 |
|------|--------|--------|------|
| 字号 | 12–14px 为主 | 正文 ≥ 16px，关键操作按钮 ≥ 18px | 儿童阅读距离与专注度 |
| 点击目标 | antd 默认 `controlHeight` = 32px（`node_modules/ant-design-vue/es/theme/themes/seed.js:52`） | **最小 44×44px** | 儿童手指精度 |
| 信息密度 | 高（表格多列） | 低（一屏一个任务） | 降低认知负担 |

### 10.2 学习端页面骨架

```
┌─────────────────────────────────────┐
│ 顶栏：模块名 / 连续天数 / 护眼状态     │  高 48px，固定
├─────────────────────────────────────┤
│                                     │
│         主任务区（单屏单任务）         │  padding 16px
│                                     │
├─────────────────────────────────────┤
│ 底部主操作条（一个主动作）             │  高 64px，安全区适配
└─────────────────────────────────────┘
```

**规则**：

| 项 | 规则 |
|----|------|
| 一屏一任务 | 学习端页面**不得**出现需要滚动才能完成的主任务 |
| 底部主动作 | 主操作固定在底部（拇指可达区），高度 ≥ 44px；一屏只允许**一个**主按钮 |
| 字号 | 正文 16px；题干 18px；主按钮文字 18px；辅助说明 14px；数值/成就 20px |
| 圆角 | 学习端卡片可用 `12px`（突破管理端的 8px 上限，因为儿童界面需要更柔和的视觉） |
| 主色 | 沿用 `#1890ff`；**成就/奖励**类元素用主题成功色 `#55D187` |
| 主题 | 学习端**固定浅色主题**，根节点显式 `data-theme="light"` |

### 10.3 判对错反馈的视觉规范

这是学习端最关键的一屏，必须与红线 R-02 呼应。

| 状态 | 视觉 | 文案原则 |
|------|------|----------|
| 答对 | 成功色 `#55D187` 的柔和底 + 图标，**不放大音量式动效** | 「对了」+ 一句肯定 |
| 答错 | 危险色 `#ED6F6F` 的柔和底；**不使用纯红大面积填充**（避免挫败感） | 「再看一次」+ 指向错在哪一步 |
| 需申诉 | 中性灰底 + 「我不同意」链接 | 说明判定依据来源 |

**强制规则**：

1. 反馈区必须显示**判定来源**标记：来源为规则时显示「按答案判定」，来源含模型时显示「AI 辅助讲解，判定以规则为准」。
2. 判定依据（basis）必须可展开查看。
3. 答错时**先显示错在哪一步**，再显示完整解析（顺序不可颠倒）。
4. 不出现「你太笨了」「错误次数：3」这类负向表述；错误次数以中性方式呈现或干脆不呈现。

### 10.4 闯关与奖励

| 项 | 规范 |
|----|------|
| 关卡卡 | 圆角 12px，卡片间距 12px，未解锁态降低对比度（`opacity:.55`）+ 锁图标 |
| 连贯天数 | 用 `#55D187` 的连续条，**不做排行榜**（R-04） |
| 奖励反馈 | 轻量动效（≤600ms），不使用全屏闪白/抖动等可能引起不适的效果 |
| 失败态 | 不用红色叉号满屏；用「再来一次」引导，且**必须给出下一步该做什么** |

### 10.5 护眼相关的界面约束

| 项 | 规范 |
|----|------|
| 蓝光过滤 | 全局 `filter` 类切换，状态持久化 |
| 休息提醒 | 阻断式遮罩：**不可自动消失**，须点击确认。遮罩 z-index 取 `1000`–`3000` 之间（§7.4） |
| 远眺引导 | 提醒页给出具体动作提示（看向 6 米外 20 秒），不只写「休息一下」 |
| 用眼时长显示 | 家长端用数字 + 进度条；孩子端**不显示**时长数字（避免看表心累），只显示状态图标 |
| 护眼色板 | 基座无对比度规范，本项目约定正文与背景对比度 ≥ 4.5:1，次要文字 ≥ 3:1；护眼遮罩使用中性浅底，不使用高饱和色 |

### 10.6 练习页的答案屏蔽（R-01 视觉实现）

对应《系统设计说明书》10.3 的 `PracticeAnswerGate` 状态机：

| 状态 | 解析区 | 说明 |
|------|--------|------|
| UNANSWERED | **不渲染到 DOM** | 不是 `display:none`，是组件根本不挂载 |
| ANSWERED | 渲染「看解析」入口按钮 | 判定结果已返回 |
| REVEALED | 渲染完整解析 | 孩子主动点击后 |

> 视觉上「看解析」按钮在 UNANSWERED 状态下**占位保留但不激活**（避免布局跳动），但解析内容不得存在于 DOM。
