4.2 本项目约定

上游的暗色是框架级能力：变量与组件都适配了，但业务页面里硬编码的 hex 不会跟着变（build/vite/plugin/theme.ts 只覆盖 antd token 与 CSS 变量，管不到业务代码里写死的颜色）。

规范 4.2（强制）： ① jeecg-study 新页面凡使用颜色，必须走 CSS 变量或 less 变量，不得硬编码 hex——否则暗色模式下会出现半深半浅。 ② 管理端与家长端跟随全局暗色开关（家长端不锁定）。 ③ 学习端与孩子端锁定浅色：根节点显式 data-theme="light"，不随全局切换——护眼场景下深色底反而增加疲劳。 ④ 暗色模式默认关闭，不作为交付验收项。
