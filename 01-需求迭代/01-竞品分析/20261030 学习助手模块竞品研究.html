核心信息速览

结论先行

  • 头部市场已经很卷，但卷的全是「题库规模」，不是「一个娃的学情」

    作业帮、小猿搜题靠 30 亿级题库与 98% 搜题命中打天下，学而思靠教研厚度与分层教学，猿辅导靠「个人学习图谱」把知识点拆成微技能点并逐个点亮。这些能力面向的是千万级陌生用户，对自家一个孩子是过剩的。本项目真正的差异化不是内容更多，而是六模块共享同一份学情数据——这在现有竞品里几乎不存在，因为它们每个模块都是独立产品线。

    品牌网 AI 学习系统横评 · 魔果云课 K12 平台测评 · 长安少年派学习软件实测

  • 最大空位在错题模块：所有产品都把「录入」做到了极致，却没人做好「复盘」

    错题类工具的竞争全部集中在拍照擦除笔迹、自动归类、导出 PDF 打印——收录能力已经过剩。真实用户反馈却是「不如手写整理错题更能加深记忆」「举一反三的出题质量偶尔差强人意」。原因是错题本 90% 的价值在「什么时候复习」和「错的到底是什么原因」，而几乎所有工具只做到分类和导出，整理完就积灰。这也正好是本项目最该做深的地方。

    菜鸟 AI 错题整理横评 · 一聚教程网 · 单词鸭英语错题集 · 长安少年派实测

  • 「数学母题过关斩将」只有一家产品真正同构：洪恩思维的应用题母题模块

    洪恩思维（小学 1–6 年级）有 185 道应用题母题，每个母题配「剖析讲解 + 子题变式练习」，官方表述就是「告别盲目刷题，一通百通，学会举一反三」——这正是需求描述里的「母题过关斩将」。其余大厂给的是「题」不是「一类题的结构」：小猿 AI 有 30 亿题库与「诊—学—练—测—评」闭环，学而思有分层教学，但都没有把母题抽象成可复用的解题模板。

  • 英语语法存在一条没人走的中间地带：查错工具只报错不教规则，课程工具讲规则但不落地

    Grammarly 拿了几乎所有「Best Overall」（Pro 约 $12/月），但评测方同时提醒：盲从接受所有建议，文章就开始「不像你」；British Council LearnEnglish Grammar 被评为 A1–A2 初学者的首选，规则清晰、结构化，却完全不对应国内教材语法点顺序。中间那一段——给国内学生、按考纲、用孩子自己的句子讲语法——是空的。

  • 语文写作模块：竞品都在发「范文和素材」，而需求要的是「技巧鉴赏」，这是两件事

    笔神作文有 500 万篇范文＋动画微课＋AI 多维批改＋人工精批，稿好语文有初中 132 点 / 高中 138 点答题技巧与文言文专题，语文天天读有分学段分体裁指导——内容储备都很厚。但它们交付的是可抄的句子；笔神自己的 FAQ 也写明「范文不建议直接抄袭照搬」。「看出一篇好作文为什么好」这件事，至今没有产品系统地做。这恰恰是本项目该占的位置。

  • 自有娃使用的真正约束不是「功能」，是「别把孩子养成伸手搜答案的人」

    行业观察反复指出搜题的风险是用户过度依赖搜题、缺乏独立思考；艾瑞也点名作业帮与学而思、猿辅导存在严重功能同质化。对一个自有工具，约束应该反过来设计：每道题先展示母题思路、再放孩子作答入口、最后才允许看解析；家长端只做「看报告 + 一句话反馈 + 推送」，不做辅导。国家卫健委监测显示我国儿童青少年总体近视率已突破 52.7%，超 75% 的家庭无法完全依靠自身完成孩子全流程学习辅导——用眼时长与护眼必须是产品指标，不是加分项。

需求拆解与产品定位

先定边界

这是一个家庭私有工具，不是面向市场的教育产品。这个前提一旦确定，很多取舍立刻变清晰：不需要增长、不需要付费墙、不需要做海量题库， 但需要数据一致性、错题不积灰、用眼可控。下表先把需求逐条拆成可验证的子问题，再给出竞品证据侧的结论。

2.1 需求要素拆解

形态小程序或 APP微信生态还是独立 APP？家长端要不要？倾向小程序 低频使用、跨设备只求同步；APP 仅在需要离线答题/护眼大屏时再考虑

2.2 定位结论：这不是一个「App」，是一个人的学习操作系统

应该做成什么样

  • 共享学情底座：一个统一的知识点 ID 体系，六个模块的题目、单词、语法点、作文段都挂到同一棵树上
  • 统一错题池：所有模块的「做错」进同一个池子，带模块、学科、知识点、错因、复习排期
  • 统一复习调度：一条间隔重复队列管全部模块（这正是竞品错题本最大的缺口）
  • 家长端只读：看报告、看趋势、留一句话，不做辅导、不做排名
  • 护眼优先：用眼时长统计、蓝光过滤、休息提醒作为硬指标

不应该做成什么样

  • 不要做搜题机：一拍照给答案的工具，会直接毁掉前五个模块的价值
  • 不要做资源仓库：把学科网那套「1200 万套资料」搬进来只会让孩子逛而不做
  • 不要做素材金句库：会导致所有作文雷同，且违背「鉴赏」的初衷
  • 不要堆通用大模型：竞品评测明确指出「通用大模型只是把矛盾的训练数据重新生成心理学话术」
  • 不要做公开社区/排行榜：单娃工具不需要社交压力，反而需要降低焦虑

对本项目最重要的一条实测结论

千问在批改时把一道正确题判成了错。这说明：AI 批改结果不能直接呈现给孩子当结论。本项目所有 AI 环节（讲题、批改、语法纠错、作文点评）都必须遵循同一规则——先展示依据、再给结论、允许申诉；涉及分数与对错的关键判定，必须有确定性逻辑兜底（题干比对、规则引擎、题型规则），AI 只做解释层。

模块 ① 地区与考纲

竞品横评

这个模块最容易被做成「资源库」，也最不该。对自家一个孩子来说，几百万套试卷是负担而不是资产。真正有用的只有一件事： 把这一个孩子所在地区、年级、教材版本的考纲拆成结构化坐标，让后面五个模块的所有内容都能挂上去。

4.2 交叉论证：这个模块真正的缺口

竞品共同做到了什么

  • 地区是硬需求且已被验证：三款独立产品（学科网、猿题库、菁优）都把「按地区筛」做成一级能力，说明家长确实在为「本省考什么」付费
  • 教材版本覆盖广：32 省地方版本、人教 / 苏教 / 北师大 / 浙教 / 沪教 / 京教 / 鲁教是事实上的最小集
  • 知识点树 + 题目挂载：菁优的「考点描述 / 分析 / 解答 / 点评」与地理通的知识树证明「考纲结构化」是共识做法

但对单娃场景全部失效

  • 规模是负担：1,294 万套资料对单个孩子等于「选择困难」，与「错题越积越多」是同一类失败
  • 没有跨模块统一坐标：猿题库的「地区 + 考点」只服务于做题，无法让背单词的考纲词、数学的母题、写作的评分点挂在同一棵树上
  • 没人把它当「地基」：所有产品都把地区当筛选项，没人把地区当全局上下文变量——这正是本项目的结构性优势

整合建议：把「资源库」改造成「坐标系」

不要收录资源，只建结构。一次配置（省 + 学段 + 年级 + 教材版本）→ 生成一棵四层坐标树：地区考纲 → 学科 → 单元/章节 → 考点， 每个考点带「题型 + 分值权重 + 常见错误类型 + 对应母题 ID」。此后：背单词的考纲词表按这棵树取子集；数学母题挂在对应考点下；英语语法点映射到中考题型（单选 / 完形 / 语法填空 / 书面表达）；语文评分点映射到中考作文分项。 这个模块的产出不是内容，而是一张「这个孩子要学什么」的地图——它必须第一个做，因为后面五个模块全靠它定位。

5.2 交叉论证：为什么「复盘」是全场最大的空位

供给端已经过剩

  • 录入能力已经免费化：拍照擦笔迹、框选、自动归类在五款免费工具里全部具备，且都宣称「基础录入、分类、导出打印全免费」
  • 大厂也免费提供：作业帮、小猿 AI 的错题本归集 + 同类题推送已内置在主 App 里，不构成付费点
  • 结论：错题录入是入场券，不是差异点

但需求端已经证伪

  • 已有用户明确反馈「整理错题不如手写更能加深记忆」——这句话直接否定了「收录即掌握」
  • 另一款头部错题工具的「举一反三」出题质量被诟病——说明复盘环节的出题质量是硬门槛
  • 行业通用建议是「错题需在 24 小时内整理」、「按知识点与错误类型（粗心 / 知识盲区）分类」——但工具只做了前半句（分类），没做后半句（排期与重做）
  • 海外工具的共识做法是间隔重复 + 定期复习，但在国内工具里几乎看不到

整合建议：把错题本做成「复盘引擎」，而不是「收纳工具」

四件事必须同时具备，缺一件就退化成积灰本：
① 错因强制标签——借用 A+ 错题本的用户自定义思路与讯飞的类型划分，固定五个维度：概念不清 / 审题偏差 / 计算失误 / 方法不会 / 时间不够。错因不是选菜单，是答完题后必须答的一个问题。
② 重做队列而非文件夹——借鉴 Anki 间隔重复 + 试卷错题宝的定向复习引擎：错题默认进入待重做队列，按掌握程度自动排期（当天 / +1 天 / +3 天 / +7 天），连续两次做对才移出。
③ 一题多变——借鉴讯飞的「情境重构变式」与洪恩的「母题剖析 + 子题变式」：一道错题至少配一道换数字、一道换情境的变式，做对变式才算真的掌握。
④ 统一入口——数学母题、背单词、语法、写作的每一次「做错」都进这一个池子。这是自有工具相对所有竞品唯一的结构性优势。

两个已被验证的坑

  • 只记图不记词：图片降低入门难度，但会形成「看图认词」的伪记忆，离开图片就懵
  • 只打卡不复习：每天贪新词数量，旧词遗忘不断堆积，复习完成度比新学量更重要
  • 工具切换过频：同时用四款不如踏踏实实跑完一本词书
  • 课内超纲污染：不按教材版本过滤，孩子会背一堆本学期不考的词，挫伤信心

三条可直接落地的机制

  • 课内词走「教材单元 1:1 映射 + 自动过滤超纲」（背单词花园做法），每单元一关，过关有可见奖励
  • 课外词走「熟词过滤 + 四档反馈 + 阶段曲线」（扇贝 + 墨墨做法），先测词汇量跳过已会的，省下的时间全给高频词
  • 词→句→篇三层（扇贝做法）：一词一义 → 造句 → 短文填词，把词放回可考试的真实语境里

整合建议：一个入口，两套算法

不要做两个 App，做一个 App 里的两条词书线。课内线：教材单元词表 1:1 映射（自动剔除超纲）→ 游戏化闯关 + 每日目标 + 连续天数，目标是不掉队； 课外线：本地区考纲高频词 + 真题熟词生义 → 熟词过滤 + 四档反馈（认识/模糊/忘记/熟知）+ 间隔重复排期，目标是提分。 两条线共用同一套复习队列与错题池：课内背错的词自动升级为课外线的优先复习项——这正是竞品做不到的，因为它们的课内课外是两条不相干的产品线。

7.2 交叉论证：「母题」到底该是什么

竞品给出的三个「母题雏形」

  • 洪恩：母题 → 子题变式（185 道应用题），配剖析讲解，最接近字面需求
  • 讯飞：错误类型 → 情境重构变式，把「为什么错」和「换个情境还对不对」接起来
  • 学而思：知识点 → 分层（基础/培优），结构化拆解但偏课程体系

大厂缺的那一样

  • 没有「一类题的解题结构」这一层抽象：给的是知识点下的题列表，不是「已知条件类型 → 关键关系 → 解题步骤链 → 易错点」
  • 过关单位错了：多数产品以「知识点」或「随机题」为进度单位，孩子感觉是「刷了 200 道」而不是「这类题我会了」
  • 判对标准单一：做对就过，没区分「蒙对」「过程对但步骤跳」「真懂」

整合建议：把「过关斩将」建立在母题结构上，而不是题量上

① 母题数据结构：每道母题固定五段——题型名 / 已知条件类型（几个变体）/ 关键关系（解题的「眼」）/ 解题步骤链（3–5 步）/ 易错点清单。这五段既能生成讲解，也能生成变式。
② 过关判据：以母题为关卡单位，过关 = 该母题下 N 道变式全对 + 能口述关键关系。口述不过关就补一句追问（讯飞的苏格拉底式），而不是直接给答案。
③ 变式生成三层：换数字（同结构）→ 换情境（同结构不同表层）→ 逆向提问（已知结果求条件）。第三层最能检验真懂。
④ 错因二分前置：在解每一步时打标——公式记错 / 步骤跳步 / 审题偏差 / 方法不会，直接继承讯飞的分型思路，让错因数据反过来指导「先补哪一关」。
⑤ 溯源到坐标：母题挂到模块 ① 的「地区考纲 → 学科 → 单元 → 考点」树上，闯关顺序 = 考纲优先级，不是随机推荐。

路线 A：查错工具（Grammarly 系）

  • 横评原话：「语法检查器在你漏掉的地方有用；当你开始把每句话磨成同一个腔调时，它就没用了」
  • 弱：英文母语者导向，不接国内考纲

路线 B：结构化课程（British Council 系）

  • 强：规则讲得清、有分级、有权威来源
  • 弱：与孩子手里正在写的句子无关，学完不会用
  • 弱：纯英语环境，语法点顺序与国内教材脱节
  • 弱：纯输入型，没有输出检验

① 句子变形器（趣味化的核心）：给一个中文意思，让学生看同一个意思的 5 种英文表达——直译版、地道口语版、书面版、考试安全版、错误示范版，并说清各自用在什么场合。这比讲「虚拟语气由 if + 过去式构成」有效得多，因为它解决的是「怎么用」而不是「是什么」。
② 错误即入口：孩子写完一句，标出错误 → 点错误 → 弹出「这个语法点的最小讲解 + 一个同类例句 + 一个反例」，然后立刻改一次。讲解永远从孩子的真实错误出发，不做预防性灌输。
③ 考纲锚定：每个语法点挂到模块 ① 的考点树，并标注对应中考/高考题型（单选 / 完形 / 语法填空 / 书面表达）——只讲这个地区这个学段要考的。
④ 趣味化玩法：句子侦探（找出错的那一句）、语法变形闯关、「我的错句收藏馆」（把写过错的句子收集起来定期回看，直接复用模块 ② 的复盘队列）。
⑤ 复用语境库：与模块 ③ 共用同一批例句——同一个词在课文、真题、原声素材里的不同用法，一次建库三处受益。

9.2 交叉论证：「鉴赏」与「积累」是两件事

竞品做的：积累

  • 金句 / 素材 / 模板：稿好语文的成语库、高级词汇、古诗词千首；笔神的素材卡片
  • 风险：所有孩子写同一个人、同一件事、同一句开头；素材库越厚，作品越雷同
  • 笔神、稿好自己提供的「文段美化」「同义转化」本质上把答案代劳了

需求要的：鉴赏

  • 拆解：看出一篇好作文为什么好——它的钩子在哪、选材角度独特在哪、结构怎么搭、哪三个句子是手法示范
  • 迁移：学到的是「可以套用到自己的题目上的写法」，不是「可以抄的句子」
  • 现有产品里只有笔神的「范文逐段讲解」沾边，但那是范例欣赏，不是结构化拆解

整合建议：从「范文库」升级为「拆解库 + 对照式批改」

① 名篇拆解库：一篇佳作拆成六层——题目钩子 / 开篇三句 / 选材角度 / 结构图 / 三个手法例句（逐句说明手法）/ 结尾回扣。每层只给「可迁移的写法」，不给可抄的句子；每层末尾附一道「换到你的题目上会怎么写」的提示题。
② 批改从「改错」升级为「对照」：批改结果不是「扣了几分」，而是「你这篇 vs 同题材佳作的差异清单」，只给最该改的三条。（借鉴笔神的多维批改 + 作文帮的温和分寸。）
③ 素材改情境库：同一个「坚持」主题下，给的是不同处境、不同年龄、不同细节的情境而不是金句，强制孩子填自己的经历。
④ 三步训练流（借鉴作文库）：审题 → 列提纲 → 写初稿，每步有系统反馈；提纲这一步必须过才能写初稿，这是防代写最有效的一步。
⑤ 真实作品闭环：每周一篇 → AI 初评 → 家长一句话反馈 → 学期末做成小册子。对照自己的学期初稿，不与他人排名——单娃工具最忌讳公开比较。
⑥ 与模块 ② 打通：写作里的「病句 / 表达问题」按错因标签进统一错题池，和数学错题共享复习排期。

怎么落地

六个模块单独看都不难，难的是让它们共用一套数据。增量追加的正确顺序，不是按开发难度，而是按「地基 → 闭环 → 增量」的顺序。

10.1 统一底座：五个共享组件

组件做什么为什么必须先有
全局上下文地区 + 学段 + 年级 + 教材版本，只配置一次，之后全局生效模块 ① 的产出是所有内容的定位依据；模块 ③ 的教材同步与模块 ④ 的考点排序全靠它
坐标树地区考纲 → 学科 → 单元 → 考点，每考点带题型、分值权重、常见错因、母题 ID六模块的内容必须能互相引用，否则退化成拼盘
统一 ID 体系题目 / 单词 / 语法点 / 作文段 / 考点各有 ID，跨模块可互引让「数学母题错因 → 关联语法点 → 关联作文评分点」这类跨模块推荐成立

统一复习调度一条间隔重复队列管全部模块（借鉴 Anki + 试卷错题宝的定向复习引擎）竞品错题本最大缺口；也是「整理完不积灰」的唯一解法

10.2 五阶段增量路线

阶段上线内容要达成的目标通过标准
V0 地基全局上下文配置 + 坐标树骨架 + 错题池（拍照录入 + 错因标签 + 重做队列）把「一个娃学什么」和「他错在哪、什么时候再练」两个问题解决掉能对任意一道错题回答：属于哪个考点、错因是什么、下次什么时候复习、变式题在哪
V1 习惯背单词模块（课内线优先：教材单元 1:1 映射 + 闯关 + 连续天数）先建立每天打开的习惯与最小成就感连续 14 天完成率 ≥ 80%，课内单元词表覆盖到当前进度
V2 主战场数学母题过关斩将（母题五段结构 + 三层变式 + 过关判据 + 错因二分）做出竞品里几乎无人做的机制差异每个母题至少 3 道变式；变式全对且能口述关键关系才算过关
V3 拓展英语语法（句子变形器 + 错误即入口）+ 课外词线（熟词过滤 + 四档反馈）补齐英语，并验证跨模块复盘是否跑得通语法错句自动进错题池并排期；课外词复习完成率 ≥ 课内
V4 沉淀语文写作（名篇拆解库 + 对照式批改 + 三步训练）+ 全模块关联推荐完成闭环，并做出与竞品最本质的差别每篇作文能给出「与同题材佳作的差异清单」；跨模块推荐命中率达可用水平

每阶段都要守住的四条红线

① 反搜题：任何练习的答案入口必须排在「孩子先作答」和「先看母题思路」之后。
② AI 只做解释层：千问的批改误判说明大模型不能当结论。判对错走确定性逻辑，AI 只负责讲解与追问；涉及分数必须有人工或家长兜底通道。
③ 护眼是硬指标：用眼时长统计、蓝光过滤、定时休息提醒、每 15 分钟强制远眺提醒——参考小学数学同步学的护眼三件套与洪恩的休息提醒。
④ 不做公开比较：家长端只看客观趋势与状态，不做同龄排名（参考斑马家长伴学模式的「专注度曲线与情绪状态」而非分数排名）。

10.3 风险清单

高
内容版权：题库、范文、真题均不可直接搬运学科网、菁优、笔神的题库与范文都是受版权保护的商业资产。安全做法：题目用自编或公开授权（如 OpenStax、CC 授权教材、各地教育考试院公开发布的样题与考纲）；范文用公开发表的获奖作品并标注出处；教材同步只做「结构映射」不做「内容复制」。
高
近视与用眼：52.7% 不是小数字国家卫健委公开监测数据显示我国儿童青少年总体近视率已突破 52.7%；超 75% 的家庭无法完全依靠自身完成孩子全流程学习辅导——这正是工具的价值，也是责任。护眼能力必须是产品指标而不是营销词。
中
搜题依赖：这是行业公认的用户伤害大盘盘点明确指出作业帮、小猿这类工具的劣势是「存在用户过度依赖搜题、缺乏独立思考的风险，需要家长合理管控」。本项目设计必须从反面规避，否则把孩子教成了搜题机器。
中
AI 幻觉与批改误判已在竞品实测中出现（千问把正确题判为错）。凡涉及分数、判对错、AI 生成讲解，都必须有确定性规则兜底 + 可申诉路径 + 人工/家长复核入口。
中
教材版本与考纲变动地区考纲、教材版本会周期性调整（学科网强调「紧跟教育政策，内容随教材修订实时更新」）。坐标树需要版本化与失效标记，否则孩子会按旧考纲学。
低
单用户规模有限，靠外部机制补足自用工具拿不到墨墨那样的 1200 亿级记忆行为数据，也拿不到学而思的教研厚度。应对方式：借 Anki 的间隔重复算法模型、扇贝的熟词过滤、洪恩的母题结构与菁优的考点四段式，用别人的机制代替自己的数据规模。
