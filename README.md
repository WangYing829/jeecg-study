# README · jeecg-study

> **jeecg-study** —— 面向**一个家庭多个孩子**的学习操作系统。
> 统一学情底座串起**地区考纲、错题复盘、背单词、数学母题、英语语法、语文写作**六个模块。
> 技术底座：JeecgBoot 3.9.2（**已拉取独立基座**）· MySQL 8（**单库 `jeecg-study`**，平台表 + 业务表同库）。

> 这是**人类入门页**。AI 协作入口在 [`AGENTS.md`](./AGENTS.md)，项目权威全文在 [`00-项目说明.md`](./00-项目说明.md)。

## 1 这个仓库是什么

一个**文档驱动 + 已落基座**的工程工作区：文档从竞品分析一路做到部署运维，源码底座已就位，业务代码待开工。

```
竞品研究 → 产品需求说明书 → 产品设计规范
                            ↓
              系统设计 / 数据库设计 / 接口设计 / 前端页面清单
                            ↓
                    测试大纲 → 测试用例 → 部署方案 → 运维手册
                            ↓
              JeecgBoot v3.9.2 基座 + jeecg-module-study 骨架
```

## 4 命名规约

| 项 | 约定 | 示例 |
|---|---|---|
| 目录 | `2位数字序号-业务名称` | `01-需求迭代` |
| 主要产物文件 | `2位数字序号-业务名称` | `01-产品需求说明书.html` |
| 主产物的 Markdown 源稿 | **与同名 HTML 同基名同目录** | `01-产品需求说明书.md` |
| 过程产物（无 HTML 对应） | `8位日期2位序号-业务名称` | `2026103019-多用户改造契约.md` |
| 导入的外部产物 | **保留原文件名** | `20261030 学习助手模块竞品研究.html` |
| 工具约定文件名 | 例外白名单，见 `00-项目说明.md` §3 | `AGENTS.md` / `README.md` |

序号在项目内**全局唯一**，跨目录不复用。

> **MD 源稿与 HTML 产物内容相同 ⇒ 用同一套命名**（同目录并列、同基名，只有扩展名不同）。
> 只有**没有 HTML 对应**的过程产物才用 `YYYYMMDDNN` 编号。

## 5 四条不可破的产品红线

| 编号 | 红线 |
|---|---|
| R-01 | **反搜题**：答案入口必须排在「孩子先作答」「先看母题思路」之后 |
| R-02 | **AI 只做解释层**：判对错走确定性逻辑，涉及分数必须有人工/家长兜底通道 |
| R-03 | **护眼是硬指标**：用眼统计、蓝光过滤、休息提醒是产品指标不是营销词 |
| R-04 | **不做公开比较**：家长端只看客观趋势与状态，不做同龄排名；并禁止家庭内比较、家长之间互不可见 |

这四条是**发布否决项**，在测试大纲里有 **24 条**可执行断言（`03-测试验证/`）。
